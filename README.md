# Martin Wek Tong Campaign Website

Responsive static campaign website for Martin Wek Tong, aspiring candidate for the National Parliamentary Seat for Constituency 8, Gogrial East County, Warrap State, South Sudan.

## Pages
- Home — campaign overview
- Biography — confirmed community and business leadership roles
- Manifesto — message from the candidate, seven proposed pillars and accountability approach
- News — newsroom ready for verified updates
- Gallery — supplied campaign photographs
- Schedule — public event schedule, populated only when dates are confirmed
- Contact — campaign contact details pending official verification
- Custom not-found view

## Deploy on Vercel
Import this repository into Vercel. It is a static HTML/CSS/JavaScript website:
- Framework preset: Other
- Build command: leave empty
- Output directory: .
- Install command: leave empty
- No environment variables are required.

## Accuracy
The website does not invent contact details, events, dates, education history or campaign achievements. The manifesto is a proposed advocacy platform, not a guarantee of outcomes. Delivery depends on the parliamentary mandate, available budgets and responsible institutions.

Before launch, confirm the candidate's official nomination wording, approve all campaign copy and add verified contact details when available.
